# Power BI Performance Tracker

An interactive Power BI dashboard developed to analyze retail sales performance and generate meaningful business insights from transactional sales data.

## 📊 Project Overview

The **Performance Tracker** dashboard provides an interactive view of retail sales performance across different branches, cities, product categories, customer segments, payment methods, and other business dimensions.

The project focuses on transforming raw sales data into meaningful visual insights using **Microsoft Power BI, DAX, and Excel**.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Microsoft Excel
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence

## 📁 Dataset

The project uses a retail sales transaction dataset containing information such as:

- Invoice ID
- Branch
- City
- Customer Type
- Gender
- Product Category
- Unit Price
- Quantity
- Tax
- Total Sales
- Date & Time
- Payment Method
- Cost of Goods Sold (COGS)
- Gross Margin
- Gross Income
- Customer Rating

The original dataset is available in:

`Dataset/Sales-Dataset2.xlsx`

## 📈 Dashboard Features

The Power BI dashboard provides analysis of:

- Total Sales
- Total Quantity
- Total Tax
- Gross Income
- Product Category Performance
- Branch-wise Sales
- City-wise Sales
- Customer Type Analysis
- Gender-wise Sales
- Payment Method Analysis
- Customer Ratings
- Interactive Filters and Slicers
